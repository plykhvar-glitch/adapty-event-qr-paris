# Adapty Prototype QR · Paris

**Live:** https://plykhvar-glitch.github.io/adapty-event-qr-paris/

A one-screen page to hold up at the Paris event: a full-size QR code for each prototype. Tap the app at the top or swipe to switch. Add `#unchaind` or `#scanner` to the link to open one straight away. On an iPhone, Share → Add to Home Screen opens it full-screen.
